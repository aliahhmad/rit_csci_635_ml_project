\begin{frame}{Neural Network Model}
    \begin{itemize}
        \item A dense multilayer perceptron was used for the neural network model.
        \item The model used the scaled feature set created during preprocessing.
        \item Class-aware training was applied to account for imbalance in loan outcomes.
        \item The network learned nonlinear relationships between borrower, loan, and credit features.
        \item Model outputs were probabilities that can be adjusted with different decision thresholds.
    \end{itemize}
\end{frame}
